# Ôn thi Thí nghiệm Sinh học Tế bào

Trang ôn thi cho 3 bài thí nghiệm: Lab 1 (Plant structures), Lab 2 (Cell division), Lab 3 (Permanent slides).

Mỗi bước có 3 phần: làm gì, tại sao, làm sai thì sao. Kèm theo:
- các chuỗi hỏi đáp "hỏi đến khi hiểu" giữa giảng viên và hai sinh viên,
- 9 câu đề mẫu có lời giải,
- bảng "Chất gì dùng cho mẫu gì",
- chế độ luyện thi và bài luyện nhận diện các kỳ phân bào bằng ảnh thật.

Nội dung do một nhóm agent Claude Haiku soạn (giảng viên → 2 sinh viên hỏi tiếp → kiểm định → chốt bài), sau đó được Claude Opus rà soát.
